Methodology Notice (Beginner Rule-Based Model):

This application uses a transparent, documented dictionary-based keyword rule system (AFINN-based polarity weights from -5 to +5). It handles basic negation (e.g., "not good" or "never happy") and word intensifiers ("very", "extremely"). It is not a deep neural network or large language model (LLM), so complex sarcasm, nuanced metaphors, or double negatives may produce simplified results.
