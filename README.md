# Application 04: Text Sentiment Analyzer

A beginner-friendly web application that classifies the sentiment of sentences or paragraphs as Positive, Negative, or Neutral using a transparent, rule-based approach.

## Features
- **Sentiment Classification:** Accurately classifies text into Positive, Negative, or Neutral categories.
- **Polarity Score:** Computes a normalized compound polarity score ranging from -1.0 to +1.0.
- **Influential Words Display:** Highlights the exact positive and negative keywords that influenced the classification score.
- **Negation and Intensifiers Handling:** Inverts polarity for phrases like "not good" or "never happy", and amplifies scores for intensifiers like "very" or "extremely".
- **Sample Sentences:** One-click sample buttons for Positive, Negative, and Neutral examples.
- **Clear Disclaimer:** Clearly explains that this uses a documented rule-based lexicon rather than a black-box AI model.

## Technologies
- HTML5
- CSS3
- JavaScript (Vanilla ES6)

## How to Run
Double-click `RUN.bat` or open `index.html` directly in any web browser.
